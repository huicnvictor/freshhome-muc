FreshHome MUC · 后台

改动会提交到网站仓库，保存后 1–2 分钟生效。

登录

需要一个只对本站仓库有权限的 GitHub Token。第一次使用：

  1. 打开 github.com/settings/personal-access-tokens/new
  2. Resource owner 选 huicnvictor，Repository access 选 Only select repositories → freshhome-muc
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. 点最下面 Generate token
  5. 生成后的那一页有个绿色框和 Copy 按钮，立刻点 Copy 贴到下面。这串只显示这一次，之后在 token 列表里看到的 github_pat_11… 是打码的、用不了。

预约日历

点日期把它设为营业日，再点时间格切换「可约 / 已约」。灰色日期是过去的，不能改。

「需间隔」是系统自动算的：紧挨已约时段前后一小时不可约，不用手动设。
